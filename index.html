今彩539｜1000期統計推演器

以最近 1000 期資料，綜合「開獎日期條件、5球開出順序、近期趨勢、最近三期九宮格」，並可選擇加入個人紫微斗數命盤特徵作娛樂性加權，推演下一期候選號碼。

本工具只能做歷史統計、walk-forward 回測與開獎後自我校正；自我校正可能改善某些回測期間的命中表現，但不能改變獎球本身的隨機機率，也不存在可保證的「最佳號碼」。

① 內建歷史資料 / 匯入更新資料

已內建 2023～2026 歷史資料，並更新至 2026/09/24；完整模型最多使用最近 1000 期。
開啟程式後會自動檢查網路上的最新資料，只補入本機尚未登錄的期別並自動記憶；若官方 API 暫時無法連線，會以公開鏡像先補齊開獎日期、期別與5個號碼，之後再自動補回精確開出順序。

⑤ 歷史回測 / 開獎後自我校正

新版V3加入「循環回推自動修正」：程式會逐期回到開獎前，用當時以前的資料先預測，再揭曉該期實際第1～第5球，找出各位置、各因子與不同時間窗的誤差後更新模型，再往下一期重複。每一輪都用後段歷史資料做 walk-forward 驗證；只有驗證分數變好才保留該輪，避免單純把已知答案硬記住。
循環回推自動修正尚未建立持久化學習模型
會把最近的精確開出順序切成「前段學習、後段驗證」；每輪只在驗證表現改善時保留，再將最佳設定重新學習全部已知期數並記憶於本機。
自我校正回測採 walk-forward：先預測，再揭曉當期結果，最後只把當期結果用於下一期。循環模式另外會反覆尋找各位置因子與時間窗差異，但只保留能改善後段驗證的輪次。
可選擇最近一期或歷史任一期，查看「事後解釋度、各球位置排名、權重如何調整」，再用更新後模型推演下一期開出順序。
九宮格定義：將號碼依 (號碼−1) mod 9 映射到 1～9 格，排列為 1-2-3 / 4-5-6 / 7-8-9；最近三期依第1～第5球各自觀察格位移動。這是本工具透明化的自訂統計特徵，不是台彩官方預測方法。
